UN Global Goal

Quality Education. This website connects to education because it shows my learning journey in web development and how I build skills through practice.

Design Thinking Process

Empathize: I thought about my audience, such as my teacher and classmates.

Define: I wanted to make a website that introduces my identity and interests.

Ideate: I planned sections like About, Images, Video, and Contact.

Prototype: I first built a simple framework before adding content.

Test: I tested layout, navigation, readability, and image placement.

Accessibility Statement

I tried to make this website easy to read and use. I used clear headings, readable fonts, strong color contrast, simple navigation, semantic HTML, and alt text for images.

Behind the Curtain

HTML: I used semantic sections to organize the website.

CSS: I used a pink cyberpunk style, grid layout, glow effects, and responsive design.

JavaScript: I used JavaScript for navigation effects, the Show More toggle, and form validation.

Challenge: The hardest part was balancing creative style with readability.

Developer Tools: I used browser developer tools to test spacing, layout, and responsiveness.

What I Learned: I learned how HTML, CSS, and JavaScript work together.
