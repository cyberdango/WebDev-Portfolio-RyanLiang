During this web development portfolio project, I learned how to plan, build, and improve a personal website using HTML, CSS, and JavaScript. At the beginning, my main goal was to create a website that could introduce myself in a clean and creative way. I wanted the website to show my personality, interests, photos, videos, and learning progress. I chose a pink cyberpunk style because it feels futuristic, personal, and visually memorable.

One important part of the process was organizing the website structure. I simplified the navigation bar into Home, About, Images, Video, and Contact because I did not want the website to feel crowded. The Home page became a simple digital identity screen with “Ryan L.” and “Building My Digital Identity.” The About section introduces who I am, including my interests in photography, card magic, video editing, technology, and creative media. The Images section is designed like an art gallery, with photos from my life and placeholders for future photography work. The Video section is prepared for two videos: one about my hobbies and one about my vehicles.

I also learned how important design thinking is in web development. Instead of only adding content, I had to think about the user experience. I considered what my teacher and classmates would see first, how they would move through the website, and whether the layout was easy to understand. I used headings, sections, cards, and spacing to make the website more organized.

One challenge I faced was balancing creative design with readability. Sometimes the cyberpunk style could become too busy, so I simplified the layout, reduced unnecessary text, and kept the main sections clean. Another challenge was working with images and making sure the gallery layout looked good before all final photos were added. I solved this by using clear image file names, short captions, and placeholder areas.

This project helped me understand how HTML, CSS, and JavaScript work together. HTML builds the structure, CSS creates the visual style, and JavaScript adds interaction, such as navigation effects or form validation. I also practiced using GitHub to save my progress with commits. Overall, this project showed me that web development is not just coding. It is also planning, designing, testing, and improving step by step.
